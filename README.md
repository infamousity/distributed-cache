# Distributed Cache with Ristretto v2, Memberlist, and Doppio

A lightweight distributed caching layer using Ristretto v2, consistent hashing, and gossip-based node discovery.

## Features

- Fast local cache (Ristretto v2)
- Distributed node discovery (Memberlist)
- Key sharding via consistent hashing
- Doppio-style API interface
- Swarm-compatible deployment
